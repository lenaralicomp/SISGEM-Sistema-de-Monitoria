# SISGEM — protótipo funcional

Protótipo web do Sistema de Gestão de Monitoria (UEA/EST).

## Arquivos
- `index.html` — estrutura da página
- `styles.css` — estilos (branco, preto e detalhes verdes)
- `app.js` — toda a lógica: dados de exemplo, regras de negócio, telas e ações

## Como abrir
Abra o `index.html` no navegador (duplo clique). Não precisa de servidor nem instalação.
Para publicar, envie os três arquivos para qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).

## Acesso
Na tela de login há botões de acesso rápido para cada perfil (senha de todas as contas: 12345678).

## Dados
Os dados ficam salvos no navegador (localStorage). Use "Restaurar dados de exemplo" no menu lateral para voltar ao estado inicial.
